# v0.0.103 – C-pilotens produktgrunnlag

Denne taggen samler den eksisterende C-pakkebyggingen i produktrepoet, uten
B-profilering eller nye databasemigrasjoner. Den er en pilotrelease, ikke en
produksjonsgodkjenning og ikke en installasjon på en kunde-VM.

## Omfang

- Felles React/Vite-produkt med en egen `customer`-byggemodus.
- Versjonert innlesing og validering av instanskonfigurasjon og statisk profil
  fra `svario-deploy`, med publiserbar nettlesernøkkel og HTTPS-origin.
- Instansnavn, logo, favicon, aksent og metadata i kundebygget.
- Passordinnlogging i C-grensesnittet; skyens markedsføringssider,
  selvregistrering, e-postlenker, BRREG-knapper og brukerstyrt kontosletting
  er ikke tilgjengelige i dette grensesnittet.
- Pakking fra en ren Git-tag med manifest, SQL-migrasjoner og SHA-256.
- Lokal presentasjonsmodus uten konfigurert backend, bare med `--preview`.
- Node-versjon i `.node-version` og profiltester med `npm run test:customer`.

Skjulte UI-funksjoner er ikke serverbasert tilgangskontroll. Auth, Nginx og
databasepolicyer må fortsatt konfigureres og testes i den enkelte installasjon.
Pakkene er merket `releaseStatus: pilot` og `installableInProduction: false`.

## Avgrensning mot B

B-profilering per arbeidsflate, Svario-adminsiden for B-profiler og tilhørende
databasemigrasjoner inngår ikke. Disse må gjennomgås, testes og committes i
en separat endring. Eksisterende lokalt B-arbeid skal bevares.

Kundens profil og driftsoppsett hører hjemme i `svario-deploy`, ikke i en
produktfork. Releasegrenen er en integrasjonsgren, ikke en varig C-utgave av
produktet. Den kan senere flettes til `main` i et avtalt publiseringsvindu.

## Bygg fra taggen

Bruk en separat, ren klone og Node-versjonen fra `.node-version`:

```sh
git switch --detach v0.0.103
npm ci
npm run test:customer
npm run build:pages
npm run package:customer -- --app-tag v0.0.103 \
  --instance demo-test --deploy-dir ../svario-deploy --output ../c-artifacts
```

`demo-test` bruker Nordvik-profilen `demo/r1` med fiktiv backend. Det er en
demopakke, ikke en fungerende labinstallasjon. Den eksakte deploycommiten
registreres i pakkens manifest. Bruk en ren, gjennomgått deployrevisjon.
Pakker skal oppbevares utenfor produktrepoet; nøkler, sertifikater og kundedata
skal aldri tas med i Git.

## Publisering er ikke utrulling

Denne releasen publiseres fra `codex/c-release-foundation`. Den eksisterende
Pages-workflowen kjører ved push til `main`, ikke ved push av denne grenen
eller taggen. Publisering av taggen skal derfor ikke endre svario.no.
VM-er, kalde kopier, plattformpakker og eksisterende labtagger skal ikke endres.

Databasemigrasjonene er identiske med produktgrunnlaget `059321a` (34 filer).
Dette er ikke en ny oppgraderingsøvelse. Nordvik-labbens nåværende `lab.sh`
krever minst én ny migrasjon ved oppgradering og må utvides før en ren
appoppdatering fra v0.0.102 til denne versjonen kan installeres.
