# v0.0.107 – ryddigere administrasjon i C-grensesnittet

Denne appreleasen samler UI-rettelsene fra Nordvik-piloten på
`codex/c-selfservice`. Den er en pilotrelease, ikke en produksjonsgodkjenning
eller en utrulling til en VM.

## Endringer fra v0.0.106

- «Administrasjon» erstatter «Instansadministrasjon» i sidemenyen,
  mobilnavigasjonen, sidetittelen og visningen for manglende tilgang.
  Brukerrollen vises som «Administrator».
- Administrasjonslenken har egen rad over Profil og Logg ut. Lenken er også
  tilgjengelig ved mobilbrekkpunktet, uten et mellomrom der begge menyer skjules.
- Lagre regler og Last inn på nytt har tydelig avstand. På smale skjermer
  står knappene under hverandre.
- Brukerlisten viser «Side X av Y», med avstand til Forrige og Neste.
  På mobil står sidetallet over knappene. En tom liste vises som «Side 1 av 1».
- Sidetallet annonseres med `aria-live`, og pagineringen har et eget
  tilgjengelig navn.

## Avgrensning

Dette er en ren appoppdatering uten nye databasemigrasjoner. Migrasjonene,
Auth-/applikasjonslogikken, repositorylaget og avhengighetslåsen er uendret
fra `v0.0.106`. Den interne ruten `/instance-admin` og administratorrettighetene
er ikke endret. Kundeprofilen ligger fortsatt separat i `svario-deploy`.

Endringene er samlet i C-arbeidsmappa. B-arbeidet, VM-ene og de kalde kopiene
er ikke en del av releasen. Ingen pakker, sertifikater, nøkler eller kundedata
skal committes sammen med kildekoden.

## Verifisering før tagging, 2026-11-18

Testet i en separat lokal kildekopi med Node `24.14.0` og låste avhengigheter:

- `npm run test:customer`: 5 tester bestått.
- `npm run test:selfservice`: 6 tester bestått, inkludert navn, avstand og
  tilgjengelig sidetall.
- `npm run build` og `npm run build:pages`: bestått.
- Produksjonsbygg i `customer`-modus med Nordvik-profilen `demo/r1` og
  `demo-test` sin fiktive backendkonfigurasjon: bestått.
- 15 nettleserkontroller med de faktiske React-komponentene og fiktive hooks:
  ni skjermbredder fra 320 til 1440 px, neste/forrige side, tom liste,
  lagre/last inn på nytt, manglende tilgang og sidemeny for vanlig bruker.
  Ingen JavaScript-feil eller eksterne HTTP-kall i testen. Desktop- og
  mobilskjermbildene er også visuelt kontrollert.

Nettlesertesten bruker fiktive data og verifiserer grensesnittet, ikke ekte
innlogging, databasepolicyer eller en installert VM. En full offlineinstallasjon
av den oppdaterte C-standardpakken er et separat teststeg.

## Bygg og kontroller en apppakke fra taggen

Bruk en ren klone på `v0.0.107`, Node-versjonen fra `.node-version` og en ren,
gjennomgått revisjon av `svario-deploy`:

```sh
git switch --detach v0.0.107
npm ci
npm run test:customer
npm run test:selfservice
npm run package:customer -- --app-tag v0.0.107 \
  --instance demo-test --deploy-dir ../svario-deploy --output ../c-v0.0.107
python3 ../svario-deploy/scripts/verify-customer-artifact.py verify \
  --deploy-dir ../svario-deploy --product-dir . --instance demo-test \
  --app-tag v0.0.107 --out-dir ../c-v0.0.107
```

`demo-test` bruker Nordvik-logo/profil med fiktiv adresse og plassholdernøkkel.
Den er egnet for byggeverifisering, ikke for installasjon i labben. Pakkens
manifest binder sammen apptaggen, produktcommiten, deploycommiten,
profilhashen og migrasjonene. Arkivet og sjekksummen skal oppbevares utenfor Git.

Taggen erstatter ikke automatisk appversjonen i en eksisterende C-oppskrift.
Oppdatering av leveranseoppskrift, full offlinepakke og VM-test skal gjøres
som et eget steg. Lokal tagging publiserer heller ingenting til GitHub
eller svario.no.
